# Publicar Morangos de Namaacha na Vercel

1. Importe este repositório na Vercel.
2. Mantenha a pasta raiz do projeto como **Root Directory**. O ficheiro `vercel.json` já define a instalação, a compilação e a pasta publicada.
3. Não é necessário configurar variáveis de ambiente para a landing page.
4. Faça o primeiro deploy e associe o domínio da marca, se já existir.

A landing page é estática e não depende do servidor API deste projeto. O endereço e a imagem absoluta para partilhas sociais podem ser definidos depois de escolher o domínio.
